**4. Add intent consumption useEffect:**

```typescript
useEffect(() => {
  if (!intent) return;
  // Guard against stale intents (Pitfall 1 — older than 5 seconds)
  if (Date.now() - intent.createdAt > 5000) {
    clearIntent();
    return;
  }
  // Capture return info BEFORE clearing intent (Pitfall: clearing before consuming)
  setDiagramReturn({ returnStack: intent.returnStack, returnLevel: intent.returnLevel });
  setHighlightedFile(intent.targetFile);
  // Auto-open the diff for the target file (async, fire-and-forget)
  void handleViewDiff(intent.targetFile);
  clearIntent();
}, [intent]);
```

Note: `handleViewDiff` is already defined in the component (line 36). The `void` keyword is consistent with Phase 06-03 pattern for fire-and-forget async calls.

The `highlightedFile` state is set synchronously (instant visual feedback in the changes panel), while `handleViewDiff` loads diff content asynchronously (Pitfall 6 from research).

const handleBackToDiagram = useCallback(() => {
