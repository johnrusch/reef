## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, `gap-1`, `p-1` |
| sm | 8px | Button padding, compact row spacing, `p-2`, `gap-2` |
| md | 16px | Default element spacing, sidebar section padding, `px-4`, `py-4` |
| lg | 24px | Section breaks between sidebar regions, `py-6` |
| xl | 32px | Not used in sidebar/breadcrumb phase |
| 2xl | 48px | Not used in sidebar/breadcrumb phase |
| 3xl | 64px | Not used in sidebar/breadcrumb phase |

Exceptions:
- Collapsed icon-only sidebar: fixed width 40px (`w-10`) — existing convention, source: C4HierarchyTree.tsx line 53
- Expanded sidebar: resizable 160px min / 400px max — source: CONTEXT.md D-04
- Breadcrumb row: `px-4 py-2` (8px vertical) — corrected from prior 6px (`py-1.5`) to conform to 4-point scale
- PanelResizeHandle: 4px wide (`w-1`) — standard react-resizable-panels convention for a minimal drag target
- Touch / click targets: 32px minimum height for tree element rows (`py-2` = 8px top + 8px bottom + 16px line = 32px)

## Color

All values reference the project's CSS custom properties defined in `src/renderer/styles/globals.css`.

| Role | Value | Tailwind Class | Usage |
|------|-------|----------------|-------|
| Dominant (60%) | `hsl(220 13% 18%)` | `bg-gray-900` | Main diagram canvas area, page background |
| Secondary (30%) | `hsl(217 19% 27%)` | `bg-gray-850` / `bg-gray-800` | Sidebar background, breadcrumb bar background, panel backgrounds |
| Accent (10%) | `hsl(217 91% 60%)` | `text-blue-400`, `bg-blue-600/20` | Active sidebar item highlight, breadcrumb clickable links, focus ring |
| Destructive | `hsl(0 62% 30%)` | `bg-red-900/20`, `text-red-400` | No destructive actions in this phase — reserved for error inline messages |

**Accent reserved for:**
1. Active C4 level row in sidebar (`bg-blue-600/20 text-blue-300`) — the currently navigated level
2. Clickable breadcrumb segments (non-current) (`text-blue-400 hover:text-blue-300`)
3. Focus ring on interactive elements (`ring-blue-500` via `--ring` CSS var)
4. Expand/collapse toggle button hover state — NOT accent, uses `hover:bg-gray-700` (secondary)

**Sidebar resize handle color:** `bg-gray-700` at rest, `bg-blue-500` on drag-active — this is the single "affordance hint" for the drag target. Source: Claude's Discretion.

**Unreachable level color:** `text-gray-600` — existing convention from C4HierarchyTree.tsx line 73. Must not use accent for unreachable states.

**Element tree sub-items (expanded under active level):** `text-gray-400` at rest, `hover:text-gray-200 hover:bg-gray-700` on hover — matches existing non-active level button styling.

## Layout Contract

### PanelGroup Layout (DiagramViewer)

```
┌─────────────────────────────────────────────┐
│  DiagramControls bar (full width)            │
├─────────────────────────────────────────────┤
│  DiagramBreadcrumbs bar (full width)         │
├──────────────┬──┬──────────────────────────┤
│  Sidebar     │▌│  Diagram canvas            │
│  Panel       │ │  Panel                     │
│  defaultSize │ │  flex-1                    │
│  20%         │ │                            │
│  min 160px   │ │                            │
│  max 400px   │ │                            │
└──────────────┴──┴──────────────────────────┘
```

- `PanelGroup direction="horizontal"` wraps only the sidebar + canvas row
- Sidebar Panel: `defaultSize={20}` (approx 20% of window), `minSize` computed from 160px, `maxSize` computed from 400px
- `PanelResizeHandle` between sidebar Panel and canvas Panel: `className="w-1 bg-gray-700 hover:bg-gray-500 active:bg-blue-500 cursor-col-resize transition-colors"`
- `autoSaveId="c4-sidebar-width"` on the PanelGroup — persists to localStorage (source: CONTEXT.md D-05)
- When sidebar is in collapsed icon-only mode (40px), the PanelGroup is bypassed: sidebar renders as a fixed-width `aside` at `w-10`, drag handle is hidden (source: CONTEXT.md D-06)

## Interaction Contract

### Sidebar Navigation (SIDE-01 fix)

- Clicking a reachable level row calls `onNavigate(level)` which updates the navigation store stack
- The highlight (`activeLevel`) is derived from `stack[stack.length - 1].level` — reads directly from store, reactive to all navigation sources (sidebar click, breadcrumb click, element canvas click, command palette)
- Bug fix target: `onNavigate` handler in DiagramViewer must call `navigationStore` methods before updating local `currentOptions` state, so the store is the single source of truth before re-render

### Sidebar Element Tree (SIDE-03)

- Only the active C4 level shows its element list expanded; all other levels show collapsed (level header only)
- Element list loads via IPC call when navigation changes to that level; result is held in local component state (not persisted)
- Clicking an element row calls the same `onNavigate(level, elementId)` callback as a canvas element click — drill-down behavior is identical
- Loading state: while IPC call is in-flight, show a single `Loader2` spinner icon (`w-3 h-3 animate-spin text-gray-500`) inline after the level label

### Sidebar Resize (SIDE-02)

- `react-resizable-panels` handles resize behavior; no custom drag logic needed
- Width persists to `localStorage` via `autoSaveId`
- Collapse button (`ChevronLeft`) hides PanelGroup; renders fixed-width `aside w-10` instead
- Expand button (`ChevronRight`) in collapsed state restores PanelGroup; `react-resizable-panels` restores last saved size

### Breadcrumb (BRCR-01)

- Each segment: `{elementName} (level)` — always shows level suffix
- Segments appear exactly once — data fix in navigation store ensures no duplicate elementNames across stack entries
- Current segment: non-clickable, `aria-current="page"` (existing, keep)
- Past segments: clickable, call `onNavigate(index)` (existing behavior, keep)

### Keyboard / Accessibility

- All sidebar buttons keep `title` attribute for tooltip (existing pattern)
- Sidebar level rows: `role="button"` or native `<button>` (keep existing `<button>` elements)
- PanelResizeHandle: `react-resizable-panels` provides built-in keyboard resize support (arrow keys when focused)
- Breadcrumb `<nav aria-label="C4 diagram breadcrumb">` (existing, keep)
