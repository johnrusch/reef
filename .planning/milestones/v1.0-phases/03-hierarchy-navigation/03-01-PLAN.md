Key implementation details:

1. Define NavigationLevel interface:
```typescript
export interface NavigationLevel {
  level: 'context' | 'container' | 'component' | 'code';
  elementId?: string;  // undefined for context level
  elementName: string; // Human-readable name for breadcrumb display
}
```

2. Define NavigationState interface:
```typescript
interface NavigationState {
  stack: NavigationLevel[];
  repositoryPath: string | null;

  // Computed
  currentLevel: () => NavigationLevel;
  canDrillDown: () => boolean;
  canDrillUp: () => boolean;

  // Actions
  push: (level: NavigationLevel) => void;
  pop: () => void;
  navigateTo: (index: number) => void;
  reset: (repositoryPath?: string) => void;
  setRepository: (path: string) => void;
}
```

3. Implement store with create():
- Initialize stack with context level: `[{ level: 'context', elementName: 'System Context' }]`
- currentLevel() returns stack[stack.length - 1]
- canDrillDown() returns currentLevel().level !== 'code'
- canDrillUp() returns stack.length > 1
- push() appends to stack
- pop() removes last item if stack.length > 1
- navigateTo(index) slices stack to index + 1
- reset() clears stack to initial context level
- setRepository() resets stack when switching repositories (important: don't carry over navigation between repos)

4. Add persist middleware for session persistence:
- Storage key: 'diagram-navigation'
- Partialize: only persist stack and repositoryPath
- Clear persisted state if repositoryPath doesn't match current repo on mount

5. Helper function for level order validation:
```typescript
const LEVEL_ORDER = ['context', 'container', 'component', 'code'] as const;
export const getNextLevel = (current: NavigationLevel['level']): NavigationLevel['level'] | null => {
  const currentIndex = LEVEL_ORDER.indexOf(current);
  return currentIndex < LEVEL_ORDER.length - 1 ? LEVEL_ORDER[currentIndex + 1] : null;
};
```

Do NOT use immer middleware (not in current stack). Use simple spread operations for immutable updates.

When user selects a different diagram type from controls (not from navigation), reset to that level. This handles the case where user manually selects "Context" from dropdown while viewing Code level.
```typescript
useEffect(() => {
  const typeLevel = currentOptions.type.replace('c4-', '') as NavigationLevel['level'];
  const currentNavLevel = navigationStore.currentLevel();

  // Only reset if navigating "up" via type selector (not via breadcrumb)
  if (typeLevel !== currentNavLevel.level) {
    const typeIndex = ['context', 'container', 'component', 'code'].indexOf(typeLevel);
    const navIndex = ['context', 'container', 'component', 'code'].indexOf(currentNavLevel.level);

    if (typeIndex < navIndex) {
      // User selected a higher level, truncate navigation
      const targetIndex = navigationStore.stack.findIndex(l => l.level === typeLevel);
      if (targetIndex >= 0) {
        navigationStore.navigateTo(targetIndex);
      } else {
        navigationStore.reset();
      }
    }
  }
}, [currentOptions.type]);
```
