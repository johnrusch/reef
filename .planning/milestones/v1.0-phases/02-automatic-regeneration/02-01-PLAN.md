2. Create src/main/services/fileWatcherService.ts implementing:

**Class Structure:**
- Singleton FileWatcherService class
- Private Map<string, FSWatcher> to track active watchers (key: `${repoPath}:${level}`)
- Import chokidar, BrowserWindow from electron, C4Level from types
- Import c4CacheService for timestamp checks

**Core Methods:**

`startWatching(repoPath: string, level: C4Level): void`
- Get file patterns for level using getFilePatterns()
- Create chokidar watcher with config:
  - persistent: true
  - ignoreInitial: true (per user decision - mark stale on new changes only)
  - ignored: ['**/node_modules/**', '**/.git/**', '**/dist/**', '**/.cache/**']
  - awaitWriteFinish: { stabilityThreshold: 100, pollInterval: 50 } (100ms debounce per Claude discretion)
  - depth: 10
- Listen for 'change', 'add', 'unlink' events
- On event, call handleFileChange()
- Store watcher in Map with key `${repoPath}:${level}`

`stopWatching(repoPath: string, level: C4Level): void`
- Get watcher from Map
- Close watcher
- Delete from Map

`stopAllWatchers(): void`
- Iterate Map and close all watchers
- Clear Map

`private handleFileChange(repoPath: string, level: C4Level, changedPath: string): void`
- Get lastGenerationTimestamp from c4CacheService
- If file mtime > lastGenerationTimestamp, emit IPC event
- Use BrowserWindow.getAllWindows() to send 'diagram:stale' event with { repoPath, level, changedPath }

`private getFilePatterns(repoPath: string, level: C4Level): string[]`
- Level-specific patterns per user decision:
  - context: [`${repoPath}/package.json`, `${repoPath}/tsconfig.json`, `${repoPath}/src/**/main.*`]
  - container: [`${repoPath}/package.json`, `${repoPath}/src/main/**/*`, `${repoPath}/src/renderer/**/*`]
  - component: [`${repoPath}/src/**/*.{ts,tsx,js,jsx}`]
  - code: [`${repoPath}/src/**/*.{ts,tsx,js,jsx}`]

`checkStalenessOnStartup(repoPath: string, level: C4Level): Promise<boolean>`
- Get lastGenerationTimestamp from c4CacheService
- If 0, return false (never generated)
- Call c4CacheService.isDiagramStale()
- If stale, emit 'diagram:stale' IPC event
- Return staleness status

**Export singleton instance:**
```typescript
export const fileWatcherService = new FileWatcherService();
```

**Error handling:**
- Log errors to console.error with context
- Don't crash on individual file events

Extend existing C4CacheService to persist last generation timestamps for staleness detection.

**Add to initializeDatabase() method:**
```sql
CREATE TABLE IF NOT EXISTS generation_timestamps (
  repo_path TEXT NOT NULL,
  level TEXT NOT NULL CHECK(level IN ('context', 'container', 'component', 'code')),
  timestamp INTEGER NOT NULL,
  PRIMARY KEY (repo_path, level)
);

CREATE INDEX IF NOT EXISTS idx_timestamps_repo ON generation_timestamps(repo_path);
```

**Add new public methods:**

`setLastGenerationTimestamp(repoPath: string, level: C4Level): void`
- Prepare INSERT OR REPLACE statement
- Store repoPath, level, Date.now()
- Call from setCachedDiagram() to keep timestamps in sync

`getLastGenerationTimestamp(repoPath: string, level: C4Level): number`
- Query generation_timestamps table
- Return timestamp or 0 if not found

`clearAllGenerationTimestamps(repoPath: string): void`
- DELETE FROM generation_timestamps WHERE repo_path LIKE '${repoPath}%'
- Called when repository cache is cleared

**Modify existing methods:**

Update `setCachedDiagram()` to also call `setLastGenerationTimestamp()`:
```typescript
async setCachedDiagram(repoPath: string, level: C4Level, diagram: string, elementId?: string): Promise<void> {
  // ... existing logic ...
  this.setLastGenerationTimestamp(repoPath, level);
}
```

Update `clearCache(repoPath: string)` to also clear timestamps:
```typescript
clearCache(repoPath: string): void {
  const keyPrefix = `${repoPath}:`;
  this.db.prepare('DELETE FROM c4_cache WHERE key LIKE ?').run(`${keyPrefix}%`);
  this.clearAllGenerationTimestamps(repoPath);
}
```

**Make getRelevantFilePatterns() public:**
- Change from `private` to `public` so FileWatcherService can use it
- Add export in type definition if needed

**Add clearAllCache() method:**
