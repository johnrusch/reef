    Update PlantUML service security validation to allow official C4-PlantUML includes while maintaining security:

    1. Locate `dangerousPatterns` check at line 60-65 in plantUmlService.ts
    2. Replace the blanket rejection with smart whitelist:
       - Allow: `!include https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/*`
       - Allow: `!include <C4/*>` (PlantUML stdlib syntax)
       - Block: All other !include, !includeurl, !import directives
    3. Implementation approach:
       ```typescript
       // Check for dangerous !include patterns (with C4-PlantUML whitelist)
       const includePattern = /!(include|includeurl|import)\s+(.+)/gi;
       const matches = plantUmlText.matchAll(includePattern);

       const c4Whitelist = [
         'https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/',
         '<C4/'
       ];

       for (const match of matches) {
         const includePath = match[2].trim();
         const isWhitelisted = c4Whitelist.some(allowed => includePath.startsWith(allowed));

         if (!isWhitelisted) {
           throw new Error(`Security: PlantUML text contains non-whitelisted include: ${match[1]} ${includePath}`);
         }
       }
       ```
    4. Add comment explaining security rationale for whitelist

    Research notes:
    - C4-PlantUML is official stdlib from plantuml-stdlib organization
    - All C4 levels require specific include: C4_Context.puml, C4_Container.puml, C4_Component.puml
    - Whitelist prevents arbitrary file inclusion while enabling C4 functionality
  </action>
