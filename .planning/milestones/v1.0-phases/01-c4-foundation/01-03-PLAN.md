  <action>
    Create AIEnricherService to add architectural insights to static analysis using Claude with prompt caching:

    **Core implementation:**

    1. **Constructor:**
       - Import Anthropic from '@anthropic-ai/sdk'
       - Accept apiKey parameter (passed from diagramGeneratorService which already has secure key management)
       - Initialize Anthropic client: `new Anthropic({ apiKey })`

    2. **enrichArchitecture(staticData: AnalysisResult, level: C4Level, elementId?: string): Promise<string> method:**
       - Use claude-sonnet-4-5-20250929 model (current flagship per research)
       - Implement prompt caching using cache_control parameter (SDK v0.78.0+ feature)
       - System prompt cached with cache_control: { type: 'ephemeral' }
       - Static analysis data cached with cache_control: { type: 'ephemeral' }
       - User message with level-specific request

    3. **System prompts by C4 level (getC4SystemPrompt(level) helper):**
       - Context level: "Identify system boundaries, external dependencies (GitHub API, file system), and primary actors. External systems are black boxes - don't model their internals."
       - Container level: "Identify deployable units: separate processes, databases, applications. Container = runtime construct that can be deployed independently. For Electron: main process, renderer process, preload script are separate containers."
       - Component level: "Identify code-level components within containers: service classes, stores, UI component groups. Component = non-deployable code organization that executes inside a container."
       - Code level: "Extract class-level implementation details: class relationships, key methods, interfaces implemented. Standard UML class diagram notation."

    4. **Prompt structure (use research Pattern 1):**
       ```typescript
       const response = await this.client.messages.create({
         model: 'claude-sonnet-4-5-20250929',
         max_tokens: 4096,
         system: [
           {
             type: 'text',
             text: this.getC4SystemPrompt(level),
             cache_control: { type: 'ephemeral' }
           },
           {
             type: 'text',
             text: JSON.stringify(staticData),
             cache_control: { type: 'ephemeral' }
           }
         ],
         messages: [{
           role: 'user',
           content: `Analyze this ${level}-level architecture and provide architectural insights for C4 diagram enrichment. Focus on: ${this.getLevelFocus(level)}`
         }]
       });
       ```

    5. **Response handling:**
       - Extract text from response.content[0].text
       - Log token usage: response.usage (includes cache_creation_input_tokens, cache_read_input_tokens)
       - Return architectural insights as string

    Error handling:
    - Catch APIError with status codes (429 rate limit, 401 auth, 500 server)
    - Throw descriptive errors for upstream handling
    - Log cache metrics for debugging

    Per research: This enables 90% cost reduction and 85% latency reduction for repeated analysis
  </action>

    2. **getCachedDiagram(repoPath: string, level: C4Level, elementId?: string): Promise<string | null> method:**
       - Generate cache key from repoPath + level + elementId
       - Check existing cache (use SQLite via better-sqlite3 per existing cacheService pattern)
       - If cached entry exists, check if stale via isCacheStale()
       - If stale, delete and return null
       - If fresh, return cached diagram

    3. **isCacheStale(repoPath: string, level: C4Level, cacheTimestamp: number): Promise<boolean> method:**
       - Get relevant file patterns for level (getRelevantFilePatterns helper)
       - Context: ['package.json', 'tsconfig.json', 'src/**/main.*']
       - Container: ['package.json', 'src/main/**', 'src/renderer/**']
       - Component: ['src/**/*.ts', 'src/**/*.tsx']
       - Code: ['src/**/*.ts', 'src/**/*.tsx']
       - Check file mtimes against cacheTimestamp
       - Return true if any file modified after cache timestamp

    4. **setCachedDiagram(repoPath: string, level: C4Level, diagram: string, elementId?: string): Promise<void> method:**
       - Store diagram in SQLite with timestamp
       - Use TTL based on level
