## Actionable Issues

### 1. REGEN-01: Premature success toast
**File:** `src/renderer/components/tabs/VisualMapTab.tsx:559-564`
**Problem:** Toast "Regenerated N levels — .reef/ updated" fires when `regenerateStaleLevels` returns, but `.reef/` write depends on the async `PlantUMLRenderer.onSvgGenerated` → `handleSvgGenerated` → `storeSvg` → `writeReefArtifacts` chain. If PlantUML fails, `.reef/` is never updated despite the toast.

### 2. STOR-03 partial: hasNewerFiles startup walk
**File:** `src/main/services/fileWatcherService.ts:362`
**Problem:** `IGNORED_DIRS` set in `hasNewerFiles` omits `.reef`. On app restart, the startup mtime walk could stat `.reef/` files and produce false-positive stale detection. Runtime chokidar exclusion is fine.

### 3. Phase 20 missing VERIFICATION.md
**Problem:** Phase 20 was marked complete without running the verifier. REGEN-01 and REGEN-02 have no formal verification evidence.
