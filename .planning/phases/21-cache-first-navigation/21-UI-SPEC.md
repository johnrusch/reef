## Interaction Contract

### Navigation click (drill-down, breadcrumb, sidebar level)

```
User clicks → Check .reef/ → HIT: render diagram (no overlay, instant)
                           → MISS (never generated): show GeneratePromptCard
                           → MISS (cached but not in .reef/): show Loader2 overlay, load from SQLite/LRU
```

- Navigation MUST NOT call `onRegenerateDiagram` unless `skipCache: true` is explicitly set by the user pressing Regenerate or Generate All.
- During generation (`isGenerating === true`): breadcrumb `disabled`, sidebar `disabled`, element clicks ignored — this is already enforced in existing code.

### "Generate All" button

- Location: DiagramControls toolbar, left of "Regenerate"
- Visible when: at context level AND at least one C4 level has `never_generated` state
- Label: "Generate All" with Sparkles icon (16px, `w-4 h-4`)
- State during generation: `disabled`, RefreshCw animate-spin, label "Generating..."
- Generates: all 4 C4 levels (context, container, component, code) sequentially
- Does NOT show a confirmation dialog (non-destructive — first-time generation)
- On completion: all 4 levels reachable in sidebar and via drill-down

### Explicit "Regenerate" button (single level)

- Existing behavior preserved: shows confirmation dialog before executing
- Confirmation copy: see Copywriting Contract
- Only modifies `.reef/` for the level being regenerated

## State Definitions

| State Key | Visible Indicator | User Action Available |
|-----------|------------------|-----------------------|
| `never_generated` | GeneratePromptCard centered in canvas | "Generate All" CTA |
| `generating` | Loader2 overlay (`bg-gray-900/75`) | None (all navigation disabled) |
| `fresh` | Diagram rendered, no badge | Regenerate (explicit) |
| `stale` | StalenessBadge (`bg-yellow-600/90`) top-left | Click badge or Regenerate button |
| `error` | AlertCircle + error message + Retry button | Retry Generation |
| cache-hit (instant) | Diagram renders without overlay | Navigate away, Regenerate |
| cache-miss (loading) | Brief Loader2 overlay while reading SQLite/LRU | Wait for load |

## Accessibility Contract

- All navigation controls (`button`) already have `title` attributes for tooltip context — maintain this pattern on new elements.
- `DiagramBreadcrumbs` uses `<nav aria-label="C4 diagram breadcrumb">` and `aria-current="page"` — preserve.
- `C4HierarchyTree` uses `<aside>` landmark — preserve.
- `disabled` buttons must not be focusable during generation — use `disabled` HTML attribute (not just opacity).
- Focus ring on SVG clickable elements: `outline: 2px solid #3b82f6; outline-offset: 2px` (existing in `globals.css`).
- "Generate All" button keyboard shortcut: none defined for this phase (out of scope).
