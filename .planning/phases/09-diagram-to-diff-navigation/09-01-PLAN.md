**1. Create `src/renderer/stores/diagramNavigationStore.ts`:**

Create a new Zustand store following the same pattern as diagramStateStore.ts and toastStore.ts (ephemeral, no persist middleware).

```typescript
import { create } from 'zustand';
import type { NavigationLevel } from './navigationStore';
import type { DiagramType } from '../components/DiagramViewer/DiagramViewer';

interface DiagramNavigationReturn {
  returnStack: NavigationLevel[];
  returnLevel: DiagramType;
}

interface DiagramNavigationIntent extends DiagramNavigationReturn {
  targetFile: string;
  createdAt: number;
}

interface DiagramNavigationStore {
  intent: DiagramNavigationIntent | null;
  setIntent: (intent: DiagramNavigationIntent) => void;
  clearIntent: () => void;
}

export type { DiagramNavigationIntent, DiagramNavigationReturn };

export const useDiagramNavigationStore = create<DiagramNavigationStore>()((set) => ({
  intent: null,
  setIntent: (intent) => set({ intent }),
  clearIntent: () => set({ intent: null }),
}));
```

Key decisions:
- No `persist` middleware — intent is consumed once, must not survive app restart (consistent with toastStore)
- `createdAt` timestamp enables stale intent detection in the consumer (5-second threshold)
- `DiagramNavigationReturn` type exported separately for CommitWorkflowTab local state (Plan 02)
- `DiagramNavigationIntent` extends return info with `targetFile` and `createdAt`

**2. Create `handleNavigateToDiff` callback:**

Add this new callback after the existing `handleRegenerateFromBadge` callback (around line 186), before `handleElementClick`:

```typescript
const handleNavigateToDiff = useCallback((filePath: string) => {
  const { setIntent } = useDiagramNavigationStore.getState();
  const { setActiveTab } = useRepositoryStore.getState();

  // Snapshot current diagram position for back navigation
  // CRITICAL: setIntent BEFORE setActiveTab (Pitfall 3 from research)
  setIntent({
    targetFile: filePath,
    returnStack: [...navigationStore.stack],
    returnLevel: currentOptions.type,
    createdAt: Date.now(),
  });

  // Switch to commit tab after intent is set
  setActiveTab('commit');
}, [navigationStore.stack, currentOptions.type]);
```

Uses `.getState()` pattern (consistent with Phase 06-03 and 07-02 decisions) to avoid re-subscriptions.
