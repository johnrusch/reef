**Export function `registerGenerationQueueHandlers()`:**

Inside, create `analyzer = new C4AnalyzerService();` (same pattern as c4AnalyzerService creates its own C4StorageService instance -- WAL mode handles concurrent access).

Register three IPC handlers:

1. `ipcMain.handle('c4-generation:enqueue', async (_, repoPath: string, repoName: string) => { ... })`:
   - Start generation in a **detached async IIFE** (do NOT await it). Return `{ queued: true }` immediately.
   - Inside the IIFE:
     - `cancellationFlags.delete(repoPath);` (clear any stale flag)
     - Initialize `completedLevels: string[] = []`
     - Broadcast initial progress: `{ repoPath, repoName, currentLevel: 'context', percent: 0 }`
     - Loop through `C4_LEVELS` with index `i`:
       - Check `cancellationFlags.get(repoPath)` -- if true, broadcast `c4-generation:cancelled` with `{ repoPath, repoName }`, delete the flag, use `getStorageService()` (import from c4StorageHandlers) to call `deleteDiagramsForRepo(repoPath)` for cleanup, then return.
       - `const level = C4_LEVELS[i];`
       - `const percent = Math.round(((i + 1) / C4_LEVELS.length) * 100);`
       - try: `await analyzer!.generateC4Diagram(repoPath, level);`
       - On success: push `level` to `completedLevels`, broadcast `c4-generation:progress` with `{ repoPath, repoName, currentLevel: level, percent }`
       - catch: broadcast `c4-generation:complete` with `{ repoPath, repoName, success: false, errorMessage: err.message, completedLevels }`, then return (stop processing further levels).
     - After loop completes successfully: broadcast `c4-generation:complete` with `{ repoPath, repoName, success: true, completedLevels }`

2. `ipcMain.handle('c4-generation:cancel', async (_, repoPath: string) => { ... })`:
   - Set `cancellationFlags.set(repoPath, true);`
   - Return `{ cancelled: true }`

3. `ipcMain.handle('c4-generation:get-cost-estimate', async (_, repoPath: string) => { ... })`:
   - Return a heuristic estimate (no async analysis). Per RESEARCH.md: TARGET_TOKENS = 15000, 4 levels, haiku pricing.
   - `const tokensPerLevel = 15000;`
   - `const levels = 4;`
   - `const totalTokens = tokensPerLevel * levels;`
   - `const estimatedCost = 0.03;` // ~$0.008 per level x 4
   - Return `{ totalTokens, estimatedCost, levels, summary: \`Estimated: ~${(totalTokens / 1000).toFixed(0)}k tokens (~$${estimatedCost.toFixed(2)})\` }`

**CRITICAL ANTI-PATTERNS TO AVOID:**
- Do NOT `await` the generation inside the `ipcMain.handle` callback. The IIFE must be detached (no await on it).
- Do NOT import from renderer files.
- The cancellation cleanup should call `getStorageService().deleteDiagramsForRepo()` to remove partial results -- import `getStorageService` from `c4StorageHandlers`.

In the `contextBridge.exposeInMainWorld('reef', { ... })` call, add the implementation:
```typescript
c4Generation: {
  enqueue: (repoPath: string, repoName: string) => ipcRenderer.invoke('c4-generation:enqueue', repoPath, repoName),
  cancel: (repoPath: string) => ipcRenderer.invoke('c4-generation:cancel', repoPath),
  getCostEstimate: (repoPath: string) => ipcRenderer.invoke('c4-generation:get-cost-estimate', repoPath),
  onProgress: (callback: (event: any, data: any) => void) => {
    ipcRenderer.on('c4-generation:progress', callback);
    return () => ipcRenderer.removeListener('c4-generation:progress', callback);
  },
  onComplete: (callback: (event: any, data: any) => void) => {
    ipcRenderer.on('c4-generation:complete', callback);
    return () => ipcRenderer.removeListener('c4-generation:complete', callback);
  },
  onCancelled: (callback: (event: any, data: any) => void) => {
    ipcRenderer.on('c4-generation:cancelled', callback);
    return () => ipcRenderer.removeListener('c4-generation:cancelled', callback);
  },
},
```

Follow the exact same pattern as `c4Storage.onStateChanged` for the event subscriptions (returns unsubscribe function).
