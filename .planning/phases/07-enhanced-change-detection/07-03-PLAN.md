<objective>
Fix chokidar v4 incompatibility that prevents file change detection from working.

Purpose: Chokidar v4.0.3 removed glob pattern support. FileWatcherService.getFilePatterns() returns glob patterns like `src/**/*.ts` which v4 treats as literal paths (matching nothing). This means chokidar watches zero files, fires zero events, and the entire change detection pipeline is dead. UAT Tests 2 and 3 both fail with "nothing happens when files change."

Output: FileWatcherService that watches directory paths (chokidar v4 compatible) with file extension filtering in the event handler, plus startup staleness check that walks directories instead of relying on glob expansion.

2. **Add `isRelevantFile()` method** — filters chokidar events by extension per level:

```typescript
private isRelevantFile(filePath: string, level: C4Level): boolean {
  const ext = filePath.split('.').pop()?.toLowerCase() || '';

  switch (level) {
    case 'context':
      // Context watches for main entry point and config files
      return filePath.endsWith('package.json') ||
             filePath.endsWith('tsconfig.json') ||
             /main\.[jt]sx?$/.test(filePath);
    case 'container':
      // Container watches all files in main/renderer directories
      return true;
    case 'component':
    case 'code':
      // Component and code watch TypeScript/JavaScript source files
      return ['ts', 'tsx', 'js', 'jsx'].includes(ext);
    default:
      return false;
  }
}
```

4. **Fix `isDiagramStale()` for startup check** — replace the current implementation that skips glob patterns with a proper recursive directory walk using `readdir`:

```typescript
import { stat, readdir } from 'fs/promises';

private async isDiagramStale(
  repoPath: string,
  level: C4Level,
  generationTimestamp: number
): Promise<boolean> {
  try {
    const paths = this.getWatchPaths(repoPath, level);

    for (const watchPath of paths) {
      try {
        const pathStat = await stat(watchPath);

        if (pathStat.isFile()) {
          // Concrete file — check directly
          if (this.isRelevantFile(watchPath, level) && pathStat.mtimeMs > generationTimestamp) {
            return true;
          }
        } else if (pathStat.isDirectory()) {
          // Directory — walk recursively checking relevant files
          if (await this.hasNewerFiles(watchPath, level, generationTimestamp)) {
            return true;
          }
        }
      } catch {
        // Path doesn't exist, continue
        continue;
      }
    }

    return false;
  } catch (error) {
    console.error(`Error checking staleness for ${repoPath}:${level}:`, error);
    return true; // Default to stale for safety
  }
}
```

5. **Add `hasNewerFiles()` helper** — recursive directory walk with the same ignore patterns and extension filter:

```typescript
private async hasNewerFiles(
  dirPath: string,
  level: C4Level,
  generationTimestamp: number
): Promise<boolean> {
  const IGNORED_DIRS = new Set(['node_modules', '.git', 'dist', 'dist-electron', '.cache', 'build', 'coverage']);

  try {
    const entries = await readdir(dirPath, { withFileTypes: true });

    for (const entry of entries) {
      if (entry.isDirectory()) {
        if (IGNORED_DIRS.has(entry.name)) continue;
        if (await this.hasNewerFiles(join(dirPath, entry.name), level, generationTimestamp)) {
          return true;
        }
      } else if (entry.isFile()) {
        const fullPath = join(dirPath, entry.name);
        if (this.isRelevantFile(fullPath, level)) {
          const fileStat = await stat(fullPath);
          if (fileStat.mtimeMs > generationTimestamp) {
            return true;
          }
        }
      }
    }

    return false;
  } catch {
    return false;
  }
}
```
