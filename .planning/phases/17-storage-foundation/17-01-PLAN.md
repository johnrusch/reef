    **Step 1: Create types file** `src/main/services/reef/reefStorageTypes.ts`

    ```typescript
    import { z } from 'zod';

    export const REEF_SCHEMA_VERSION = 1 as const;
    export const REEF_DIR = '.reef';

    export const ReefMetaSchema = z.object({
      schemaVersion: z.literal(REEF_SCHEMA_VERSION),
      level: z.enum(['context', 'container', 'component', 'code']),
      generatedAt: z.string(),
      modelUsed: z.string().optional(),
      promptVersion: z.string().optional(),
      tokensUsed: z.number().optional(),
    });

    export type ReefMetaJson = z.infer<typeof ReefMetaSchema>;

    // Flat levels get files directly in .reef/ (per D-01)
    export const FLAT_LEVELS = ['context', 'container'] as const;
    export type FlatLevel = typeof FLAT_LEVELS[number];

    // Nested levels get subdirectories keyed by parent element ID (per D-02)
    export const NESTED_LEVELS = ['component', 'code'] as const;
    export type NestedLevel = typeof NESTED_LEVELS[number];
    ```

    **Step 2: Create service file** `src/main/services/reef/reefStorageService.ts`

    Import from `fs/promises`: `mkdir`, `writeFile`, `rename`, `unlink`, `readFile`, `access`.
    Import from `fs`: `constants`.
    Import from `path`: `join`, `dirname`.
    Import types and schema from `./reefStorageTypes`.

    Class `ReefStorageService` with these methods:

    `async writeLevelFiles(repoPath: string, level: FlatLevel, puml: string, svg: string, meta: ReefMetaJson): Promise<void>`:
    - Compute paths: `join(repoPath, REEF_DIR, '${level}.puml')`, same for `.svg` and `.meta.json`
    - Call `ensureGitattributes(repoPath)` (per D-13, idempotent)
    - Call `atomicWrite(pumlPath, puml)`, then `atomicWrite(svgPath, svg)`, then `atomicWrite(metaPath, JSON.stringify(meta, null, 2))`
    - Per D-09: individual atomic renames, sequential not grouped
    - Per D-07: per-level independent — this method handles one level at a time

    `async writeSubDiagramFiles(repoPath: string, level: NestedLevel, parentId: string, puml: string, svg: string, meta: ReefMetaJson): Promise<void>`:
    - Compute paths: `join(repoPath, REEF_DIR, level, parentId, 'diagram.puml')`, same for `.svg` and `.meta.json`
    - Call `ensureGitattributes(repoPath)`
    - Call `atomicWrite` for each file sequentially

    `async readMeta(repoPath: string, level: string, parentId?: string): Promise<ReefMetaJson | null>`:
    - Compute path: if parentId, `join(repoPath, REEF_DIR, level, parentId, 'diagram.meta.json')`, else `join(repoPath, REEF_DIR, '${level}.meta.json')`
    - Try `readFile(metaPath, 'utf8')`, catch -> return `null`
    - Try `JSON.parse(content)`, catch -> return `null`
    - `const result = ReefMetaSchema.safeParse(parsed)` — if `!result.success` return `null` (per D-05: unrecognized schemaVersion treated as missing)
    - Return `result.data`

    `async ensureGitattributes(repoPath: string): Promise<void>`:
    - `const gitattrsPath = join(repoPath, REEF_DIR, '.gitattributes')`
    - Try `access(gitattrsPath, constants.F_OK)` — if succeeds, return (already exists)
    - Catch: create with content `# Reef auto-generated — prevents SVG/PUML merge conflicts\n*.svg binary\n*.puml binary\n`
    - Use `atomicWrite(gitattrsPath, content)`

    `private async atomicWrite(targetPath: string, content: string): Promise<void>`:
    - `const tmpPath = '${targetPath}.tmp'`
    - `await mkdir(dirname(targetPath), { recursive: true })` (lazy .reef/ creation per D-06)
    - `await writeFile(tmpPath, content, 'utf8')`
    - If `process.platform === 'win32'`: try `await unlink(targetPath)`, catch ENOENT only (per D-08)
    - `await rename(tmpPath, targetPath)`
    - Catch block: try `await unlink(tmpPath)` (cleanup .tmp pollution per pitfall 3), then re-throw

    Error handling: Log `.reef/` write failures as `console.warn` (Claude's discretion resolution — Phase 17 is main-process only, no toast). Callers of write methods should handle errors as non-fatal per D-10.
