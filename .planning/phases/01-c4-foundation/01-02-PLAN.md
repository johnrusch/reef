<task type="auto">
  <name>Implement ts-morph static analyzer service</name>
  <files>
    src/main/services/c4/staticAnalyzerService.ts
  </files>
  <action>
    Create StaticAnalyzerService using ts-morph to extract deterministic TypeScript structure:

    **Core implementation:**

    1. **Constructor and initialization:**
       - Import { Project } from 'ts-morph'
       - No ipcMain registration (this is internal utility, not exposed to renderer)

    2. **analyzeProject(repoPath: string): Promise<AnalysisResult> method:**
       - Initialize ts-morph Project with tsConfigFilePath
       - Use skipFileDependencyResolution: true to avoid loading node_modules
       - Add source files selectively: `project.addSourceFilesAtPaths('src/**/*.{ts,tsx}')`
       - Extract structure by calling helper methods
       - Detect technologies from package.json dependencies
       - Find entry points (main.ts, App.tsx patterns)
       - Return AnalysisResult with all extracted data

    3. **Helper methods (all private):**
       - extractClasses(project): ClassInfo[] - iterate sourceFiles, getClasses(), extract name/methods/properties/implements
       - extractInterfaces(project): InterfaceInfo[] - iterate sourceFiles, getInterfaces(), extract properties/extends
       - extractImports(project): ImportInfo[] - getImportDeclarations(), extract moduleSpecifier/namedImports
       - extractExports(project): string[] - find exported symbols
       - buildDependencyGraph(imports): DependencyGraph - map file-to-file dependencies
       - detectTechnologies(repoPath): string[] - read package.json, extract framework names (React, Electron, Zustand, etc.)
       - findEntryPoints(project): string[] - detect main.ts, App.tsx, index.ts patterns

    4. **Memory optimization (per research pitfalls):**
       - Use forgetNodesCreatedInBlock() in loops to release memory
       - Avoid calling type checker methods unless needed
       - Limit to source files only (no node_modules)

    Follow code examples from research:
    - Use classDecl.getInstanceMethods().map(m => m.getName()) pattern
    - Use importDecl.getModuleSpecifierValue() for imports
    - Use sourceFile.getFilePath() for file references

    Error handling:
    - Catch tsconfig.json not found, return empty structure with error message
    - Handle corrupt TypeScript files gracefully (skip and log)
  </action>
