<task type="auto">
  <name>Task 2: Create C4StorageService with v1.1 schema</name>
  <files>src/main/services/c4/c4StorageService.ts</files>
  <action>
Create C4StorageService class that replaces the TTL-based c4CacheService:

1. **Constructor**: Accept optional dbPath (defaults to app.getPath('userData')/diagrams/diagram_storage.db)
   - Create diagrams directory if not exists
   - Initialize database with WAL mode and foreign keys
   - Run integrity check on startup (PRAGMA integrity_check)
   - If corruption detected: backup corrupted file, create fresh database

2. **initializeDatabase()**: Create v1.1 schema
   ```sql
   CREATE TABLE IF NOT EXISTS diagram_storage (
     id INTEGER PRIMARY KEY AUTOINCREMENT,
     repo_path TEXT NOT NULL,
     level TEXT NOT NULL CHECK(level IN ('context', 'container', 'component', 'code')),
     element_id TEXT,
     diagram_content TEXT NOT NULL,
     diagram_metadata TEXT,
     state TEXT NOT NULL DEFAULT 'fresh' CHECK(state IN ('never_generated', 'generating', 'fresh', 'stale', 'error')),
     error_message TEXT,
     model_used TEXT NOT NULL,
     prompt_version TEXT NOT NULL,
     tokens_used INTEGER,
     generation_cost REAL,
     created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
     updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
     UNIQUE(repo_path, level, element_id)
   );

   CREATE INDEX IF NOT EXISTS idx_repo_level ON diagram_storage(repo_path, level);
   CREATE INDEX IF NOT EXISTS idx_state ON diagram_storage(state);
   ```
   - Set PRAGMA user_version = 1 after schema creation

3. **Path normalization**: All repo_path values normalized to forward slashes (cross-platform)

4. **Methods**:
   - getDiagram(repoPath, level, elementId?): Returns StoredDiagram | null
   - storeDiagram(diagram: StoredDiagram): void - INSERT OR REPLACE
   - updateState(repoPath, level, state, elementId?, errorMessage?): void
   - getState(repoPath, level, elementId?): DiagramState
   - getAllDiagramsForRepo(repoPath): StoredDiagram[]
   - deleteDiagramsForRepo(repoPath): void - NOT called when repo removed (per user decision)
   - clearAllDiagrams(): void - For settings "Clear All" button
   - getStorageStats(): { path: string, sizeBytes: number, diagramCount: number }
   - close(): void - Close database connection

5. **WAL mode configuration** (STOR-03):
   - PRAGMA journal_mode = WAL
   - PRAGMA synchronous = FULL
   - PRAGMA wal_autocheckpoint = 1000

6. **No TTL expiration logic** - Remove all time-based deletion. Diagrams persist until manually cleared or regenerated.

Reference existing pattern: src/main/services/cacheService.ts for database initialization.

<task type="auto">
  <name>Task 3: Create MigrationService for v1.0 to v1.1 migration</name>
  <files>src/main/services/c4/migrationService.ts</files>
  <action>
Create MigrationService class that handles one-time migration from v1.0 cache to v1.1 storage:

1. **Version detection**:
   - V1_0_VERSION = 0 (v1.0 had no user_version set)
   - V1_1_VERSION = 1 (v1.1 schema)
   - detectVersion(db): Read PRAGMA user_version

2. **Migration lock** (prevent multiple instances):
   - Use electron-store to set 'v1_1_migration_in_progress' flag
   - Check flag on startup, abort if another instance migrating
   - Clear flag in finally block

3. **needsMigration()**:
   - Check if v1.0 cache database exists at old location (userData/cache/diagram_cache.db)
   - Check if migration already completed (electron-store 'v1_1_migration_completed')

4. **migrate()** method:
   - Open v1.0 database as readonly
   - Open v1.1 database (new location: userData/diagrams/diagram_storage.db)
   - Wrap migration in transaction for atomicity
   - For each diagram in v1.0 diagram_cache table:
     a. Check if TTL would have expired (using v1.0 TTL constants from research)
     b. If expired: set state = 'stale'
     c. If not expired: set state = 'fresh'
     d. Map v1.0 columns to v1.1 schema (diagram_type -> level extraction)
     e. Handle element_id = null for root-level diagrams
   - If any diagram fails to migrate: log warning, continue (mark as never_generated)
   - Set user_version = 1 on new database
   - Close v1.0 database

5. **cleanupV1Cache()**:
   - Delete v1.0 database file (userData/cache/diagram_cache.db)
   - Delete associated WAL files if present
   - Only called after successful migration

6. **V1.0 TTL constants** (for determining staleness):
   - CONTEXT_TTL = 7 * 24 * 60 * 60 * 1000 (7 days)
   - CONTAINER_TTL = 3 * 24 * 60 * 60 * 1000 (3 days)
   - COMPONENT_TTL = 24 * 60 * 60 * 1000 (1 day)
   - CODE_TTL = 6 * 60 * 60 * 1000 (6 hours)

7. **extractLevelFromDiagramType(diagramType: string)**:
   - Parse v1.0 diagram_type to extract C4Level
   - Handle format: "c4_context", "c4_container", etc.

Per user decision: Silent migration, no UI unless failure. Failed diagrams marked as never_generated.
