**Part A — ChangeBadge component (src/renderer/components/DiagramViewer/ChangeBadge.tsx):**

Create a new React component with these props:

```typescript
interface ChangeBadgeProps {
  /** Count of directly changed elements at current level */
  directCount: number;
  /** Count of elements with changed children (inherited) */
  inheritedCount: number;
  /** File paths that changed (for tooltip display) */
  changedFiles: string[];
}
```

Implementation:

1. Return `null` if `directCount + inheritedCount === 0`.

2. Render a badge container with amber styling consistent with DiagramStateBadge's stale palette:
   - Outer: `group relative` (for CSS hover tooltip)
   - Badge: `flex items-center gap-1.5 px-2.5 py-1.5 bg-amber-500/20 border border-amber-500/30 rounded-md cursor-help`
   - Text: `text-xs font-medium text-amber-300`
   - Show direct count: `"{directCount} changed"` if directCount > 0
   - Show separator dot: `·` in `text-amber-500/70` if both counts > 0
   - Show inherited count: `"{inheritedCount} affected"` in `text-amber-400/70` if inheritedCount > 0

3. Tooltip implementation — CRITICAL: DiagramPanel has `overflow-hidden` on its root div. The Tailwind `group-hover:visible absolute` pattern will be clipped. Use one of these approaches:

   **Recommended approach — Fixed position tooltip with useRef:**
   - Use `useState<boolean>(false)` for `showTooltip`
   - Use `useRef<HTMLDivElement>(null)` on the badge container
   - On `onMouseEnter`: set `showTooltip(true)`, compute `badgeRef.current.getBoundingClientRect()` to get position
   - On `onMouseLeave`: set `showTooltip(false)`
   - Render tooltip with `position: fixed`, `top` = badge bottom + 4px, `left` = badge left
   - Tooltip styling: `bg-gray-900 border border-gray-700 rounded-lg shadow-xl p-3 z-[60]` (z-60 above the z-50 toasts)
   - Use `ReactDOM.createPortal(tooltipElement, document.body)` to escape any overflow container

   Tooltip content when `changedFiles.length > 0`:
   - Header: `"{changedFiles.length} file(s) changed:"`  in `text-xs text-gray-400 font-medium mb-2`
   - File list: `<ul>` with `space-y-0.5 max-h-48 overflow-y-auto`
   - Each file: `<li>` with `text-xs text-gray-300 font-mono truncate`, show only filename (`file.split('/').pop()`) with full path as `title` attribute
   - If no changedFiles: show "No file details available" in `text-xs text-gray-500 italic`

4. Export the component as a named export.
